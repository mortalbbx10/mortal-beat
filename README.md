# BeatMarket - Premium Beat Selling Website

BeatMarket is a modern, responsive website for selling and purchasing music beats. This platform connects music producers with artists looking for high-quality beats for their projects.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Beat Catalog**: Browse beats by genre, mood, BPM, and more
- **Audio Player**: Preview beats with an integrated audio player
- **Shopping Cart**: Add beats to cart and manage purchases
- **User Authentication**: Register and login functionality for both artists and producers
- **Licensing Options**: Different licensing tiers for each beat

## Pages

1. **Home Page**: Featured beats, categories, and testimonials
2. **Beats Catalog**: Browse and filter the complete beat collection
3. **Shopping Cart**: Review selected beats and proceed to checkout
4. **Login/Register**: User authentication pages
5. **Individual Beat Page**: (To be implemented) Detailed view of a single beat

## Technologies Used

- HTML5
- CSS3 (with custom variables and responsive design)
- JavaScript (vanilla JS, no frameworks)
- Font Awesome for icons

## Getting Started

1. Clone this repository
2. Add the required image files to the `/images` directory (see `/images/README.md`)
3. Add the required audio files to the `/audio` directory (see `/audio/README.md`)
4. Open `index.html` in your browser to view the website
